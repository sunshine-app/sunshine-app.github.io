## 🏗️ 系统架构

### 整体处理流程

### 🧠 核心技术详解
1. 基于 PaddleDetection 的目标检测模型
	属性	说明
	框架	PaddleDetection（飞桨目标检测工具套件）
	任务	藻类目标检测与分类
	模型	根据场景需求定制化配置与训练
	
	训练流程：
		数据准备：用户上传图像数据，系统自动完成预处理与标注辅助
		模型选型：基于 PaddleDetection 选择适合的检测模型架构
		模型训练：自动化训练，支持参数调优
		模型评估：训练完成后自动评估检测精度，辅助用户判断模型质量

2. 在线推理与批量辅助标注
	属性	说明
	推理方式	在线推理（实时检测） + 批量推理（批量处理）
	辅助标注	批量推理结果用于辅助用户标注，提升标注效率
	推理加速	FastDeploy 推理引擎加速
	
	工作流程：
		用户上传待检测图像
		系统调用训练好的模型进行在线推理
		返回检测结果（目标位置 + 类别）
		批量推理模式可辅助用户完成大规模数据标注

3. 模型加密与 DLL 封装
	属性	说明
	加密方式	C++ 双重绑定物理机加密
	推理框架	FastDeploy（Windows 离线推理）
	输出格式	DLL（适用于 GPU 和 CPU）
	
	加密方案 —— 双重绑定物理机加密：
		绑定层级	绑定对象	作用
		第一层绑定	CPU 序列号 + 网卡 MAC 地址	将模型与特定硬件绑定，防止非法复制
		第二层绑定	硬盘序列号 + 自定义加密因子	进一步增强破解难度，确保模型安全性
		
	DLL 封装特性：
		提供标准 C 接口，便于其他语言调用
		同时发布 GPU 版与 CPU 版 DLL，适应不同硬件环境
		支持 Windows 系统下的离线推理

4. FastDeploy Windows 离线推理
	属性	说明
	框架	FastDeploy（飞桨推理部署工具套件）
	平台	Windows（支持 GPU / CPU）
	输入	加密导出的模型文件
	输出	藻类检测结果（位置 + 类别 + 置信度）

	FastDeploy 推理流程：
		"""
		text
		加密模型 → 解密加载 → FastDeploy Runtime → 推理计算 → 结果输出
												↑
											 图像输入
		"""

	部署优势：
		🔹 轻量高效：专为部署优化，推理速度快
		🔹 跨平台支持：一套代码适配多种硬件
		🔹 易于集成：支持 C++、Python 等多种语言接口
