### 🧠 核心技术详解
智能体协同架构（LangGraph）
本系统基于 LangGraph 构建多智能体协同工作流，每个 Agent 负责一个特定阶段的任务。

1. VLM 图像理解与规范检索
2. 像素级裂缝分割
3. 拓扑化测量
4. LLM 结构化报告生成
5. PDF 报告整合输出
