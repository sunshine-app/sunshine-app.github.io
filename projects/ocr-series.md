### 2. 文本检测 —— 精准定位文本区域

| 模型 | 用途 | 优化点 |
| :--- | :--- | :--- |
| **DBNet** | 文本行/单词区域检测 | 针对手写场景优化，提升检测召回率 |
| **YOLO 系列** | 特定场景的快速检测 | 填空题/作文场景的定制化调优 |

**检测优化策略：**
- 针对手写文本的**粘连笔画**，调整 DB 网络的感受野
- 针对作文场景的**多行文本**，优化行间距敏感度

### 3. 文本生成 —— 解决数据稀缺

| 模型 | 用途 | 技术要点 |
| :--- | :--- | :--- |
| **ScrabbleGAN** | 生成手写英语数据 | 条件生成，可控制文本内容和书写风格 |
| **FsFont-GAN** | 生成手写中文数据 | 基于 PyTorch 实现，适配中文字符的复杂结构 |

### 4. 文本识别 —— 多场景定制化

| 模型 | 架构 | 适用场景 | 优化点 |
| :--- | :--- | :--- | :--- |
| **CRNN** | CNN + RNN + CTC | 英语词汇识别 | 轻量化，适合填空题快速识别 |
| **SVTR** | 单视觉Transformer | 英语作文/短语识别 | 无需RNN，并行计算，效率更高 |
| **ViT** | Vision Transformer | 中英文混合识别 | 全局注意力，适合复杂场景 |

**场景定制化策略：**

| 场景 | 策略 | 效果 |
| :--- | :--- | :--- |
| **英语填空题** | 轻量 CRNN + 词汇约束 | 通过率 **>97%**，TPS **10** |
| **英语作文** | SVTR + 语言模型纠错 | 篇章通过率 **>90%**，单词准确率 **>97%** |
| **中文手写** | ViT + 多任务学习 | 准确率 **>97%**，TPS **30** |

### 5. 公式识别 —— 图像到 LaTeX 翻译

| 属性 | 说明 |
| :--- | :--- |
| **任务定义** | 将手写数学公式图像转换为 LaTeX 序列 |
| **模型架构** | Transformer（Encoder-Decoder） |
| **创新点** | 将识别任务建模为“图像语义 → LaTeX 序列”的翻译问题 |

**模型架构：**

```
┌─────────────────────────────────────────────────────────────────────┐
│                    Transformer 公式识别架构                         │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│   ┌──────────────┐                                                │
│   │  公式图像     │                                                │
│   └──────┬───────┘                                                │
│          │                                                         │
│          ▼                                                         │
│   ┌──────────────────────────────────────────────────────────┐    │
│   │  CNN 特征提取                                            │    │
│   │  提取图像特征图，按 Patch 切分                           │    │
│   └──────────────────────┬───────────────────────────────────┘    │
│                          │                                         │
│                          ▼                                         │
│   ┌──────────────────────────────────────────────────────────┐    │
│   │  Transformer Encoder                                     │    │
│   │  图像特征编码，捕捉全局上下文                            │    │
│   └──────────────────────┬───────────────────────────────────┘    │
│                          │                                         │
│                          ▼                                         │
│   ┌──────────────────────────────────────────────────────────┐    │
│   │  Transformer Decoder                                     │    │
│   │  自回归解码，逐 Token 生成 LaTeX 序列                   │    │
│   └──────────────────────┬───────────────────────────────────┘    │
│                          │                                         │
│                          ▼                                         │
│   ┌──────────────────────────────────────────────────────────┐    │
│   │  LaTeX 序列输出                                          │    │
│   │  \frac{1}{2} + \sqrt{x^2 + y^2} = ...                  │    │
│   └──────────────────────────────────────────────────────────┘    │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

**关键技术点：**
- **损失函数**：交叉熵损失 + 计数损失（约束 Token 数量）
- **Token 标准化**：对 LaTeX Token 进行统一标准化处理，提升泛化能力
- **伪标签生成**：多个模型各自生成伪标签，辅助数据标注
- **评估方法**：开发基于 LaTeX 序列的评估指标，确保识别效果

### 6. 表格识别 —— 结构化数据提取

| 属性 | 说明 |
| :--- | :--- |
| **任务** | 识别手写/印刷表格的单元格结构和文本内容 |
| **技术方案** | 结构解析 + 单元格检测 + 文本识别 |

**实现思路：**
1. **表格结构识别**：检测表格的行列线，提取单元格坐标
2. **单元格内容识别**：对每个单元格区域调用文本识别模块
3. **结构化输出**：输出 JSON 格式的表格数据

### 7. 表格识别 —— 结构化数据提取（细化版）

在实际业务中，表格识别的核心难点在于：**手写内容与印刷表头边界常存在交叉，以及扫描/拍照场景下的形变和光照不均问题**。本方案的核心创新在于通过**分层版面分析 + 区域级配准**来精准定位手写位置，后期也探索和调研了端到端表格识别，序列化输出HTML格式的表格内容。

**三阶段处理流程：**

```
┌─────────────────────────────────────────────────────────────────┐
│                   表格识别三阶段流程                             │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   阶段一：表格结构解析                                           │
│   ┌─────────────────────────────────────────────────────────┐  │
│   │  输入：表格图像                                         │  │
│   │  输出：单元格区域集合（印刷表头/手写填空）               │  │
│   │  方法：基于线条检测 + 版面分析，提取单元格边界框         │  │
│   └─────────────────────────────────────────────────────────┘  │
│                              │                                  │
│                              ▼                                  │
│   阶段二：区域类型判别                                           │
│   ┌─────────────────────────────────────────────────────────┐  │
│   │  对每个单元格区域进行二分类：                            │  │
│   │  • 印刷内容（表头/题目）→ 直接复用像素区域              │  │
│   │  • 手写填空区域 → 执行区域外扩（膨胀）后裁剪子图        │  │
│   └─────────────────────────────────────────────────────────┘  │
│                              │                                  │
│                              ▼                                  │
│   阶段三：内容识别                                               │
│   ┌─────────────────────────────────────────────────────────┐  │
│   │  印刷内容：调用印刷体识别模型                           │  │
│   │  手写内容：调用手写识别模型                             │  │
│   │  输出：结构化 JSON（按单元格索引组织）                  │  │
│   └─────────────────────────────────────────────────────────┘  │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

**关键创新点：**

| 创新点 | 解决的问题 | 实现方式 |
| :--- | :--- | :--- |
| **区域类型判别** | 避免将印刷表头误送入通用文本识别模型 | 对每个单元格区域进行二分类（印刷/手写），分类后再分别送入针对性更强的专用模型，提升各自识别精度 |
| **手写区域外扩策略** | 手写内容常紧贴或超出格子边界 | 对手写区域进行矩形外扩（膨胀），防止内容被截断，然后裁剪该区域送入识别模型 |
| **配准式区域定位** | 表格形变、扫描畸变导致格子边界不准 | 利用版面分析结果与预先标注的表格模板进行配准，将分析出的坐标映射到模板中对应的语义格，按单元格索引（第几行第几列）组织输出，确保数据对齐 |
