### 核心设计理念

| 设计原则 | 说明 |
| :--- | :--- |
| **分层处理** | 块级 → 行级，由粗到精，逐步聚焦，降低单模型复杂度 |
| **区域归属关联** | 通过 IOU 计算，将行级文本精准归属到对应的块级区域，构建“块-行”层级结构 |
| **双架构冗余** | 两套不同架构的识别模型，满足“两评”准则，兼顾速度与精度的不同需求 |
| **结构化输出** | 标准化 JSON 格式，便于与下游系统（如数据库交叉校验）直接对接 |

## 🧩 核心技术详解

### 1. 第一层级：块级区域分割

| 属性 | 说明 |
| :--- | :--- |
| **模型** | Yolo11S-seg-large |
| **输入** | 预处理后的整张试卷抬头图像 |
| **输出** | 像素级类别掩膜 + 最小外接旋转矩形（四边形） |

### 2. 第二层级：行级文本分割

| 属性 | 说明 |
| :--- | :--- |
| **模型** | Yolo11S-seg-small |
| **输入** | 整张试卷抬头图像（或块级裁剪区域） |
| **输出** | 每个文本行（姓名、报名号、座位号、学科）的像素级掩膜 + 最小外接四边形 |

### 3. 区域归属关联（IOU 匹配）

通过计算每个行级四边形与各个块级四边形的 **IOU（交并比）** ，将行级区域归属到最匹配的块级区域。

### 4. 双架构文本识别

为兼顾识别精度与算法鲁棒性，系统集成了两种架构截然不同的文本识别模型，满足“两评”准则（两种独立方法交叉验证）。

### 5. 条形码识别

| 属性 | 说明 |
| :--- | :--- |
| **工具** | ZBar 图像扫描库 |
| **输入** | 块级区域中的“条形码区域”裁剪图像 |
| **输出** | 条形码文本内容 |

**实现方案：**
- 从块级区域分割结果中，提取“条形码区域”的裁剪子图
- 调用 ZBar 库进行解码
- 支持常见一维码（Code128、Code39、EAN-13 等）

## 📝 总结

本项目通过**双层版面分析 + IOU 层级关联 + 双架构识别**的技术方案，实现了试卷抬头学生信息的自动化、高精度提取，并已实际服务于上海市教育考试院的中考成绩复核工作。

核心技术价值：
1. **双层版面分析**：块级 → 行级，由粗到精，有效降低了单模型处理的复杂度
2. **IOU 层级关联**：通过交并比计算，精准构建“块-行”层级结构
3. **双架构冗余**：满足“两评”准则，兼顾速度与精度的不同业务场景
4. **标准化输出**：结构化 JSON 数据，便于下游系统无缝对接
