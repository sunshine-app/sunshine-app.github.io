## 🧠 核心技术详解

### 1. 视觉感知 —— 让机器人“看见”世界

| 属性 | 说明 |
| :--- | :--- |
| **硬件** | JAI 2D 工业相机 + 条形光源 |
| **软件** | OpenCV（图像预处理、多目标检测定位） |
| **任务** | 在高速传送带上实时识别无序来料的位置 |

**技术方案：**

```python
# 图像处理 Pipeline 示意
image_capture()          # 相机采集
    ↓
preprocessing()          # 图像增强、去噪、灰度化
    ↓
object_detection()       # 多目标检测与定位
    ↓
pose_estimation()        # 目标位置估计
    ↓
coordinate_output()      # 坐标数据输出 → 通信模块
```

**关键优化：**
- **样本采集与增强 Pipeline**：负责样本采集、筛选、去重及图像增强，提升模型泛化能力
- **目标点云处理**：多目标物体拆分，实现模块间高效数据通信
- **光照鲁棒性**：配合条形光源，减少环境光变化对检测精度的影响

### 2. 机器人控制 —— 让机器人“动”得精准

| 属性 | 说明 |
| :--- | :--- |
| **开发平台** | CODESYS |
| **编程语言** | ST（结构化文本，类 C 语言） |
| **核心功能** | 轨迹规划、I/O 控制、气源控制、抓取逻辑 |

**关键功能实现：**

| 功能模块 | 实现方案 | 解决的问题 |
| :--- | :--- | :--- |
| **目标点云去重** | 基于空间距离的聚类去重 | 避免同一目标被重复抓取 |
| **边界预测** | 根据传送带速度和目标位置预测 | 确保抓取点在有效工作空间内 |
| **无零点跟踪** | 动态坐标系映射 | 适应传送带连续运动，无需回零 |
| **轨迹规划** | 关节空间插值 + 笛卡尔空间规划 | 实现平滑、高效的抓取路径 |

### 3. 系统集成 —— 打通“视觉-通信-控制”全链路

| 属性 | 说明 |
| :--- | :--- |
| **通信协议** | 自定义 TCP（解决粘包问题） |
| **消息队列** | Kafka（异步消息通信） |
| **实时性保障** | 数据队列 + 栈缓存设计 |

**通信架构：**

```
┌─────────────────────────────────────────────────────────────────────┐
│                        通信架构设计                                 │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│   ┌──────────────┐                      ┌──────────────┐          │
│   │  视觉模块    │  ─── 自定义 TCP ───▶ │  控制模块    │          │
│   │  (目标检测)  │                      │  (机器人)    │          │
│   └──────┬───────┘                      └──────┬───────┘          │
│          │                                      │                  │
│          ▼                                      ▼                  │
│   ┌──────────────────────────────────────────────────────┐        │
│   │                    Kafka 消息队列                     │        │
│   │  视觉数据 Topic  │  控制指令 Topic  │  状态反馈 Topic │        │
│   └──────────────────────────────────────────────────────┘        │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

**关键技术点：**

1. **自定义 TCP 协议**：
   - 设计专用数据帧格式，包含帧头、数据长度、校验位
   - **粘包处理**：采用“长度前缀 + 定长帧头”方案，解决高速数据流中的粘包问题
   - 构建数据队列和栈缓存，确保数据有序处理

2. **Kafka 异步通信**：
   - 视觉模块 → Kafka Producer（生产目标数据）
   - 控制模块 → Kafka Consumer（消费控制指令）
   - 解耦视觉与控制模块，提升系统吞吐量

3. **实时性保障**：
   - 数据队列缓存，防止突发流量导致的数据丢失
   - 多线程设计，确保图像采集、通信、控制互不阻塞
