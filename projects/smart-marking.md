## 🧠 核心技术详解

### 1. 选择题批阅 —— Qwen-VL Grounding 任务创新

| 属性 | 说明 |
| :--- | :--- |
| **任务定义** | 任意位置手写作答识别与批阅留痕 |
| **模型** | Qwen-VL（微调） |
| **创新点** | 定义为 **Grounding 任务**，将识别问题转化为视觉定位问题 |
| **难点攻克** | 解决草稿信息干扰、任意位置作答的识别难题 |

**技术方案：**

传统方案依赖固定区域的 OCR 识别，但实际试卷中，学生可能在任意位置作答，且存在草稿、涂改等干扰信息。

本方案创新性地将选择题批阅定义为 **Grounding 任务**：
1. **输入**：试卷图像 + 题目区域提示
2. **处理**：Qwen-VL 在图像中**定位**作答标记的位置
3. **输出**：作答位置坐标 + 识别内容 + 批阅结果

```
┌─────────────────────────────────────────────────────────────┐
│                 Qwen-VL Grounding 任务流程                    │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   ┌──────────────┐      ┌──────────────┐                   │
│   │  试卷图像     │────▶│  Qwen-VL     │───▶ 定位作答位置    │
│   │  + 题目提示   │      │  视觉定位    │                    │
│   └──────────────┘      └──────────────┘                   │
│                                                    │        │
│                                                    ▼        │
│                                        ┌──────────────┐     │
│                                        │ 识别内容      │     │
│                                        │ + 批阅结果    │     │
│                                        └──────────────┘     │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**效果：**
- ✅ 任意位置的作答标记（画圈、打勾、涂黑、字母）均可识别
- ✅ 草稿、涂改等干扰信息被有效抑制
- ✅ 批阅留痕精准映射到原题区域


### 2. 解答题批阅 —— 三层分割模型

| 属性 | 说明 |
| :--- | :--- |
| **任务** | 获取学生解答题作答区域，解决复杂书写场景下的精确分割 |
| **模型** | Yolo11（定制化分割） |
| **创新点** | 三层分割架构 + 子题作答区域算法 |

**技术方案：**

解答题批阅面临的最大挑战是：学生作答区域不规则、可能超出给定答题框、存在多层书写叠加等。

本方案提出**三层分割模型**：

```
┌─────────────────────────────────────────────────────────────┐
│                     三层分割模型架构                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   ┌───────────────────────────────────────────────────┐    │
│   │  第1层：题区域分割                                 │    │
│   │  识别整道题目在试卷中的位置边界                    │    │
│   └───────────────────────────────────────────────────┘    │
│                            ▼                               │
│   ┌───────────────────────────────────────────────────┐    │
│   │  第2层：子题区域分割                               │    │
│   │  拆分为小题（（1）、（2）、①、② 等）              │    │
│   └───────────────────────────────────────────────────┘    │
│                            ▼                               │
│   ┌───────────────────────────────────────────────────┐    │
│   │  第3层：作答区域分割                               │    │
│   │  精准提取学生手写笔迹区域                          │    │
│   └───────────────────────────────────────────────────┘    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**核心创新：**

- **超框作答处理**：检测学生作答是否超出给定答题区域，并动态扩展搜索范围
- **双层排序与行归并**：解决学生在题区域中多层书写（如先答上部、再补下部）导致的排序错乱
- **子题作答区域约束**：基于子题区域的空间位置，约束大模型的批阅推理范围


### 3. 数学批阅 —— 空间位置关系约束（幻觉抑制）

| 属性 | 说明 |
| :--- | :--- |
| **任务** | 数学解答题的自动批阅与评分 |
| **模型** | Qwen3（针对性微调） |
| **创新点** | 基于空间位置关系的批阅算法 + 视觉结构约束推理 |

**问题背景：**

大语言模型在数学批阅中容易出现“幻觉”——例如，公式识别错误但模型仍能编造出看似合理的过程、或对明显错误的步骤给出自相矛盾的评分。

**解决方案——双重约束机制：**

```
┌─────────────────────────────────────────────────────────────────┐
│                    视觉结构约束推理流程                          │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   ┌──────────────┐      ┌──────────────┐                      │
│   │  图像空间结构 │────▶│  约束条件生成 │                      │
│   │  （行位置、    │      │  （行号绑定、  │                      │
│   │   缩进、分组） │      │   分组约束）   │                      │
│   └──────────────┘      └──────────────┘                      │
│                                │                               │
│                                ▼                               │
│   ┌──────────────┐      ┌──────────────┐                      │
│   │  手写识别结果  │────▶│  大模型推理   │───▶ 结构化批阅结果     │
│   │  （LaTeX序列） │      │  (Qwen3微调) │                      │
│   └──────────────┘      └──────────────┘                      │
│                                ▲                               │
│   ┌──────────────┐            │                               │
│   │  空间约束     │────────────┘                               │
│   │  （位置关系）  │                                            │
│   └──────────────┘                                            │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

**创新点详解：**

1. **空间位置关系批阅算法**：
   - 将每个解题步骤与其在图像中的**空间位置（行号、缩进层级）** 绑定
   - 大模型的推理结果需与空间结构对齐，避免“张冠李戴”

2. **视觉结构约束机制**：
   - 要求大模型在推理时**显式引用图像中的空间信息**作为依据
   - 例如：“根据第3行公式推导...”、“结合上方第2行的结论...”
   - **效果**：显著抑制了 LLM 的幻觉现象，提升了批阅结果的准确性与可解释性
